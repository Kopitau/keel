# CHG-019 Astra / taotie 审查后的优化授权范围

用户阅读本任务的官方 Astra 指南与 taotie 使用审查结论后，明确要求全面实施上述优化，然后调研 spexcode。审查依据见 RES-910；新增实现细节与验证结果留在工作版规划及 worklog。

## 授权范围

围绕既有七个目标，实施此前报告的六类优化：当前状态与历史职责分离；功能证据与提交/交付状态分离；按验收类型呈现证据；局部不确定只限制受影响动作并延续已有授权；保留充分调研而不把候选自动变成实施义务；按风险和实际变化验证、按需加载技能流程。

包括相应脚本、技能、模板、说明与回归验证，以及实际发现的范围内缺陷修复。需求 v10 / 总览 v6 保存生成的实施细节并保持 working，旧确认版本保留。全部优化与验证完成后，再定位并调研 spexcode，交付有来源的借鉴建议。

## 边界

这是实施范围授权，不是用户确认新需求/计划全文、验收新代码、合并、推送或发布的声明。不自动引入 spexcode 的机制、依赖或代码；不修改 taotie 正在运行的业务工作区，不启动历史 frontier。只有新增实质性选择或外部动作才需要新授权。
