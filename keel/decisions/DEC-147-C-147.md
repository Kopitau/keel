# DEC-147 F24.5 技能镜像统一用复制

## 问题

Claude Code 的技能镜像（DEC-094/C-94）在 macOS 上是否改用符号链接？

## 选项对比

macOS 用软链、Windows 用复制（平台分叉，且仓库里会出现平台相关 symlink，Git for Windows 处理有坑）／ **三平台一律复制**。

## 推荐理由

镜像本就是脚本可重建的产物，复制没有实际损失；统一行为消除一整类平台差异 bug。

## 用户决定原话

「全部同意」（F24 六点）

## 影响

DEC-094/C-94 的「Windows 用复制不软链」扩展为**三平台一律复制**。
