# DEC-151 免构建：直接运行 .ts

## 问题

TS 源码是直接运行还是编译成 JS？

## 选项对比

**直接跑 .ts**（选定）：零构建步骤，源码即运行物。代价是必须限制在「可擦除语法」子集。
**编译成 JS**：支持更老的 Node，但重新引入构建步骤与「改了忘重新编译」这一整类 bug，且 agent 读到的源码与实际运行的产物分离。

## 推荐理由

零构建消除一整类 bug；对 agent 尤其重要——它读到的 .ts 就是实际执行的代码，不存在 dist 与源码不一致导致的误判。语法子集限制可由 tsconfig `erasableSyntaxOnly` 机器强制，不靠自觉。

## 用户决定原话

「全部同意」

## 影响

gate 以 `.ts` 源码形式直接运行（`node gate.ts`）。**语法约束（tsconfig `erasableSyntaxOnly: true` 强制）**：禁用 `enum`、`namespace`、旧式装饰器、构造函数参数属性；类型导入必须 `import type`；相对导入必须带文件扩展名。违反者由 DEC-154 的类型检查门禁拦下。
