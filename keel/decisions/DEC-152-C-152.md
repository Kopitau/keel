# DEC-152 测试运行器：内置 node:test

## 问题

gate 自身的测试用什么运行器？

## 选项对比

**内置 `node:test`**（选定）：零依赖；实测可直接运行 `.ts` 测试文件（1 passed）；**自带 JUnit reporter**（`--test-reporter=junit` 实测输出标准 JUnit XML）。
**Vitest**：watch/快照/断言更丰富，DX 更好；但引入 devDependency 与 node_modules。

## 推荐理由

零依赖与「运行时仅用内置模块」原则一致；JUnit 输出天然对接证据协议（DEC-033/C-33）所需格式，无需适配层。DX 差距对一个门禁工具而言不构成决定性因素。

## 用户决定原话

「全部同意」

## 影响

gate 自身测试 = `node --test` + `--test-reporter=junit`（证据用）。
**边界澄清**：本条只管 **gate 自身**；keel 所管理的用户项目仍按各自测试画像（DEC-126/C-126）使用 pytest / Vitest / Playwright 等，不受影响。
取代 DEC-126、DEC-139 中「gate = pytest 核心级」的表述。
