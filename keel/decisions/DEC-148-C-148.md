# DEC-148 F24.6 跨平台一致性测试

## 问题

如何证明三平台行为真的一致，而不是「理论上一致」？

## 选项对比

人工抽查（不可靠）／ 只测 Windows（现状）／ **同一组 fixture 在多平台产出相同结论，进 CI 矩阵**。

## 推荐理由

这是 DEC-143 的验收手段：没有一致性测试，「三平台门禁结论一致」就只是一句声明。同时纳入框架自验收（DEC-139/C-139）。

## 用户决定原话

「全部同意」（F24 六点）

## 影响

同一组 fixture 在 Windows 与 macOS 上必须产出**相同的门禁结论、相同的规范化哈希、相同的追溯矩阵**；CI 矩阵增加 macOS runner（Linux 本已在跑）。并入 F23 框架自验收（DEC-139）。
