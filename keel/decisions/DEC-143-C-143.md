# DEC-143 F24.1 正式支持矩阵

## 问题

keel 正式支持哪些操作系统？原设计只把 Windows 写进实测要求。

## 选项对比

仅 Windows（现状，不足）／ Windows+macOS（用户新要求）／ **Windows+macOS+Linux**（Linux 已是隐含要求：CI 权威门禁跑在 GitHub Actions Linux runner 上，见 DEC-045/C-45）。

## 推荐理由

三平台的门禁结论必须一致，否则"CI 复算是唯一权威"这条会因平台差异失效。Linux 不是可选项而是既成事实，写明比默认好。

## 用户决定原话

「全部同意 2 进行更新」（2 = 确认 Linux 作为 CI 环境纳入正式支持矩阵）

## 影响

Windows / macOS = 开发机一等公民；Linux = CI 运行环境一等公民。三者门禁结论、哈希、追溯矩阵必须一致（见 DEC-148）。
