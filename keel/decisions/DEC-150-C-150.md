# DEC-150 Node 版本基线 ≥22.18.0

## 问题

gate 要求的最低 Node 版本是多少？原生类型剥离（DEC-149 的前提）并非所有版本可用。

## 选项对比

**≥22.18.0**（选定）：该版起类型剥离免标记（已核实：2025-07-31 发布，commit 8d1f5df313 unflag --experimental-strip-types；本机 v22.19.0 实测可跑）。Node 22 LTS 维护至 2027-04。
**≥24 LTS**：故事更干净（类型剥离更成熟），但把仍在 22 LTS 的机器挡在门外。
**≥20 + 构建步骤**：兼容面最大，但重新引入构建（与 DEC-151 冲突）。

## 推荐理由

22.18 是能力下界的真实位置；Node 22 仍是 LTS 且广泛部署，无理由排除。24 作为未来主线同样纳入 CI 矩阵，防止只在一条线上验证。

## 用户决定原话

「全部同意」

## 影响

最低 Node 22.18.0；**CI 矩阵测 Node 22 LTS + 24 LTS**（× 三平台，见 DEC-148）。启动器（DEC-146）须检测版本并在低于基线时给出明确错误，不得静默降级。官方仍将类型剥离标为 experimental，复审条款见 DEC-149。
