# DEC-146 F24.4 启动器与 git hooks

## 问题

gate 在三个平台上如何被一致地启动？macOS 通常只有 `python3` 没有 `python`，Windows 反之；解释器探测失败会让门禁静默失效。

## 选项对比

各平台各写一套（维护三份，易漂移）／ 硬编码解释器路径（换机即坏）／ **双启动器 + 自动探测运行时**。

## 推荐理由

启动器只是薄壳，逻辑仍在同一份 gate 里（DEC-101 的「一份脚本五处调用」原则不变，仅运行时改变，见 DEC-149）。git hooks 用 `#!/bin/sh` 薄壳：macOS/Linux 原生、Windows 走 Git Bash，三平台都成立。

## 用户决定原话

「全部同意」（F24 六点）

## 影响

提供 `gate.sh`（macOS/Linux）+ `gate.ps1`（Windows），自动探测运行时；git hooks 一律 `#!/bin/sh` 薄壳转调 gate。
