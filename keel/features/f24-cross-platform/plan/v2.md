# F24 跨平台支持 — 规划 v2

确认即冻结。本版把已有规范化哈希/启动器契约与真实跨平台证据条件逐条对账。

## 本版范围

- config 与文档一致声明 Windows/macOS 开发、Linux CI；路径只用 runtime API，casefold 冲突 FAIL。
- 所有批准/证据/legacy manifest hash 统一 UTF-8 无 BOM + LF；`.gitattributes` 强制 LF。
- `gate.sh`/`gate.ps1` 版本门一致，hooks 为 sh 薄壳；镜像三平台复制。
- 同 fixture 的 Windows/macOS/CI 结果必须以真实运行证据比较，不能用本机推断。

## 非范围

不复制 gate 逻辑；单一 Windows 运行不能解除跨平台 manual AC。

## 测试义务

REQ-024/AC-1..6 一一对应 `[machine-doc, auto, auto, auto, auto, manual]`。自动缝为 `gate hash/check/sync` 和双启动器；AC-6 记录 OS/版本、commit、fixture hash、命令、退出码、输出和结果 hash。

1. 规范化 hash/path/casefold/launcher 本地契约（verify: `node --test tests/w1-skeleton.test.ts tests/dec148-fixture.test.ts`）。
