# F22 既有框架迁移 — 规划 v2

确认即冻结。本版保留只读迁移边界，并为 0.8.0 legacy RES manifest 定义语义与报告落点。

## 本版范围

- Trellis/Superpowers/docs 仍按映射表生成未确认初稿；源树不删不改，冲突和无法归类进入报告。
- `<0.8.0→>=0.8.0` 且用户明确 `y` 后，升级前快照中的标准/深度零 URL RES 才可进入唯一 manifest；绑定 ID、相对路径、规范化全文 hash、源/目标版本和日期。
- 同一个真实 updater 黑盒同时承载 REQ-022/AC-6 与 REQ-025/AC-7，避免同义反复。

## 非范围

F22 不负责 CLI 交互实现；由 F23 提供 update 缝。不得改写旧 RES。

## 测试义务
