# F10 问题日志与防复发闭环 — 规划 v2

确认即冻结。本版把 ISS 打开门槛、关闭字段和自动评审攻击探针协议拆清。

## 本版范围

- 打开 blocking ISS 至少要有 finding、同指纹和可运行 repro；关闭时必须补根因、修复、为何未早发现、防线选择与证据。
- `review ingest` 只在攻击探针首次退出 0 时开 blocking ISS；缺命令或首次非 0 必须拒绝。
- `review clear` 只接受同一命令从 0 变非 0，并追加每次运行；三轮未清零熔断。

## 非范围

不复制 F7 的 reviewloop 实现；F10 负责问题生命周期契约与记录结构。
