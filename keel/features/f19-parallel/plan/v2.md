# F19 多人团队 + 多 agent 并行 — 规划 v2

确认即冻结。本版把分支/worktree 政策收束为三档，并以 frontier/文件重叠辅助认领。

## 本版范围

- 单人日常允许 trunk；新增大功能推荐 `keel/F-编号-短名` worktree；第二功能并行或第二人出现时强制隔离。
- 双认领报警；换手留记录；预计触碰文件重叠时串行或先定接口。
- `blocked_by`/frontier 是读取端，worktree 对被阻塞功能只 WARN；真正并行隔离仍是阻断规则。

## 非范围

不为单人每次小改强制 worktree；不引入心跳锁。
