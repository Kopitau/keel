# F6 测试与完成证据 — 规划 v2

确认即冻结。本版实现 v4 的 AC↔verification 协议、按已声明完成功能收口和 review 证据绑定。

## 本版范围

- 每个 REQ 的 acceptance 与 verification 必须等长，类型只能是 `auto`、`machine-doc`、`manual`。
- `auto` 只认最高可用缝上的黑盒测试名；`machine-doc` 认可运行结构检查；`manual` 必须带证据条件，替身只能是带解除条件的 proxy。
- summary.md 才进入强制验收；全库缺口仍显示。verify.json 保留 review 状态和追加式 `repro_runs`。

## 非范围

不新增覆盖率或变异测试门；不把 comment/fixture 字符串当追溯。

## 测试义务

REQ-006/AC-1..8 的 verification 全为 `auto`，统一挂在 `gate trace`、`gate verify`、`gate check` 三个 CLI 缝；必须覆盖等长/非法类型、claimed scope、proxy WARN、测试删除基线、tree hash stale、review 证据保留等正反向路径。

## 内部步骤

1. requirements verification parser + 等长/枚举判据（verify: `node --test tests/chg010-verification.test.ts`）。
2. trace 输出 verification 与 claimed scope，proxy 不冒充 PASS（verify: `node tools/gate/gate.ts trace`）。
3. verify/evidence 保存 review 追加历史并做 stale 对账（verify: `node --test tests/w3-verify.test.ts tests/chg010-review-loop.test.ts`）。
