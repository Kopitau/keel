# 鲁棒性清单（C-31 核心级功能代码）

DEC-160：不问「谁来攻击框架」，问「脏输入和失败会不会让功能说谎或留下半成品」。须实际构造并运行，不接受只读代码推理。

## 检查项

- 空输入、超长输入、特殊字符、非 ASCII、数值极值
- 依赖不可用（缺文件、命令不在 PATH、网络关闭）
- 脏数据 / 截断 JSON / 错编码
- 并发或连续重跑是否幂等
- 中途失败是否留下半成品状态（部分写入的记录、半份证据、未设执行位）

## 纪律

只报影响正确性与需求达成的问题（C-41）。

## 边界输入（REQ-028/AC-1，CHG-013）

- 空 / 超长 / 特殊字符 / 非 ASCII / 极值——实际构造这些输入运行，不靠读代码推理。
